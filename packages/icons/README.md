# Pattern Icons

`@ptrn/icons` contains the icon set of the Pattern Design System.

## Installation

```bash
npm install @ptrn/icons
```

## Icon types

| Type       | Source                                             |
| ---------- | -------------------------------------------------- |
| `material` | [Material Symbols](https://fonts.google.com/icons) |
| `nowhere`  | Custom icons drawn for the design system           |

## Usage

Icons should be imported directly:

```tsx
import { SvgWork } from '@ptrn/icons/Work';
```
