# Pattern UI

`@ptrn/react` contains the React components of the Pattern Design System.

## Installation

```bash
npm install @ptrn/react
```

```bash
npm install --peer @ptrn/icons react react-dom
```

## Usage

Wrap your app with a styles provider to apply the theme:

```tsx
import { StylesProviderNowhere } from '@ptrn/react/StylesProviderNowhere';
```

## Testing

To test all components

```bash
npm run test
```

To test a specific component

```bash
npm run test -t <componentname>
```
