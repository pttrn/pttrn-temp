# Contributing to @ptrn/react

Thank you for considering contributing to `@ptrn/react`.

## How to Contribute

**Clone the repository**

```bash
git clone https://github.com/pttrn/pttrn.git
```

**Create a new branch**:

```bash
git checkout -b feature/your-feature-name
```

**Make your changes**: Implement your feature or bug fix.

**Stage and commit your changes**: Use [semantic versioning](https://semver.org/) for your commit messages.

```bash
git add .
git commit -m "feat: Description of your feature"
```

**Push to your branch**:

```bash
git push origin feature/your-feature-name
```

**Create a Pull Request**: Provide a clear description of your changes.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on the [GitHub issue tracker](https://github.com/pttrn/pttrn/issues) with a detailed description.

Thank you for your contributions!
